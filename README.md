## What is MedBase?

MedBase is a free **offline medicine search app for Android**.
Search any medicine by brand name or generic name and instantly see its **price, generic name, side effects, and group**, even without internet.

Useful for pharmacy staff, medical and pharmacy students, and anyone who wants quick medicine information.

## ✨ Features

- 🔍 Fast medicine search (brand name or generic name)
- 💰 Medicine price
- 🧬 Generic name and what is inside
- ⚠️ Side effects in simple words
- 🗂️ Browse by medicine group
- 📴 100% offline after install
- 🪶 Lightweight app
